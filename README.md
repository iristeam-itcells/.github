# IRISteam IT Cells

Shared space where IRISteam IT Cells publish the tools and developments they build for Brussels local authorities (municipalities and CPAS/OCMW).

## Purpose

- Avoid developing the same tool twice in different municipalities
- Make internal developments reusable by other IT Cells
- Share good practices and documentation

## Rules

- Default license: EUPL-1.2
- Never commit passwords, API keys, tokens or personal data (GDPR)
- Each repository has a README explaining what the tool does and how to install it
- Changes to `main` go through a pull request

## Joining

Contact the organization administrators to be added to your IT Cell's team.
